# ResolveSmart

AI-Powered Grievance Redressal System for Efficient Complaint Management.

ResolveSmart is a web-based AI-powered grievance management system designed to improve complaint categorization, prioritization, duplicate detection, image-assisted verification, location-aware processing, complaint tracking, escalation, analytics, and citizen feedback.

## Technology Stack

- Frontend: HTML, CSS, JavaScript, Bootstrap
- Backend: Python Flask
- Database: MySQL
- AI/ML: Scikit-learn, spaCy, NLTK, Hugging Face Transformers
- Computer Vision: OpenCV, YOLOv8
- Maps: Leaflet.js
- Version Control: Git and GitHub
